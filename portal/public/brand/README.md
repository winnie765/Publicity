# Official Tzu Chi Singapore logo

Original bilingual artwork matching the user-supplied logo, extracted losslessly from the Foundation media release image XObject (1600 x 311 pixels, original alpha channel retained). The SVG files embed the same PNG and use a viewport to remove excess whitespace or display the emblem. No artwork, lettering or colors were redrawn or recolored.

Source: https://www.tzuchi.org.sg/assets/Media-Releases/20240928_Media-Release_Tap-or-Scan-and-Go-Tzu-Chi-Foundation-Singapore-and-2C2Ps-Pilot-Trial-of-Collecting-Flag-Day-Donations-a-Success_CN.pdf

These bundled assets are the fixed company branding. BrandLogo uses tzu-chi-singapore.svg for the full logo and tzu-chi-emblem.svg for the compact mark. The favicon is bundled at public/favicon.svg. Branding is rendered locally without a database or storage request and cannot be replaced through the Media Library or Public Site Manager.

Only the company logo and favicon are static images. All content images (including partner logos, brand pages and hero banners) use uploaded media URLs saved in database records. Missing content images show a neutral unavailable state.
